# Maple Werx placeholder

A standalone, responsive coming-soon page with a pure white background. No build step or dependencies are required.

Open `index.html` in a browser to preview it. The loading bar animates gently and respects reduced-motion preferences.

## Company logo

The page uses `maple-werx-logo.png` at up to 640px wide, preserving the image's proportions and fitting smaller screens. The company name is included in the logo. Keep the image beside `index.html` when publishing.

## Publishing

Upload `index.html` and the logo to the site's static hosting root. Configure that hosting provider for `www.maplewerx.com` and follow its DNS and HTTPS instructions. This folder does not include a hosting connection or domain configuration.
